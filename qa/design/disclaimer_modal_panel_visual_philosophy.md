# Disclaimer Modal Panel

The first-launch 18+ disclaimer uses a dedicated seam-free panel image instead of the shared modal panel. The shared panel has a horizontal divider baked into the bitmap, which reads as an accidental black line below the `Подтверждение 18+` heading.

The dedicated panel preserves the same 900x420 source geometry and the existing backplate, safety aura, acceptance glow, and image-only copy. Removing the seam makes the legal onboarding feel intentional and consistent with the polished result and rules dialogs.
