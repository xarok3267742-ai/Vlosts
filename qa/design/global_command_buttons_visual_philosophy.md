# Global Command Buttons

Command buttons are the tactile hardware of the app. They should feel like polished machine controls, not flat rectangles: layered glass, bevelled metal, internal glow, precise icon geometry, and clear pressed states. The work must stay image-first and meticulously crafted because these controls appear on first launch, home, settings, slot, dialogs, and recovery flows.

The play command is energetic but still premium. Its red surface should carry casino-cabinet depth, gold/cyan rim light, and a calm center zone for separate Russian image labels. It must not embed text, real-money cues, or payout language; the asset only supplies physical button material.

Back and settings are compact hardware keys. Back should read as an illuminated navigation arrow inside a dark glass square, while settings should read as a gear-like control dial with purple casing and cyan/gold highlights. Both need strong silhouettes at 48dp, because they are used in top bars where small visual mistakes become obvious.

Pressed states should feel mechanically depressed: slightly darker, lower contrast, inner shadow, and contained glow. The selectors remain unchanged so Android focus/click behavior is stable, while the visual system becomes consistent with the newer slot cards and home utility strips.
