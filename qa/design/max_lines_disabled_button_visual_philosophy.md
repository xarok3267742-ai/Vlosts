# Max Lines Disabled Button

The max-lines control becomes disabled when all 10 paylines are already active. It should be visually quieter than an actionable button, but it still has to explain the current state clearly because line count directly changes the total bet.

The disabled bitmap keeps a desaturated glass body and crossed payline mark, while increasing the contrast of `10` and `МАКС`. This makes the right-side control readable on the Roman slot's dark gold background without making it look tappable.
