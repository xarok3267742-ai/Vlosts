# Roman Payline Markers

Roman Reels needs payline markers that feel cast into the same bronze-and-marble cabinet as the reels. The markers should read like a physical side rail with numbered coin chips, not a generic neon overlay borrowed from Violet Fortune. Their purpose is still instructional: lines 1-10 must remain instantly visible, but the material language should be Roman arcade hardware rather than purple casino chrome.

The center of the asset stays transparent and quiet so symbols, reel depth, win halos, and payline feedback remain dominant. Visual weight belongs on the extreme left and right rails, with a restrained bottom badge for the total line count. Bronze, gold, and cyan are used as crafted material accents; no additional gambling claims, prize language, or real-money cues are introduced.

This layer remains image-only and accessibility-neutral except for the existing `slot_paylines` content description on the ImageView. The craftsmanship target is precise alignment: same 1080x1120 frame, same layout bounds, theme-specific appearance. It should look like it was tuned against emulator screenshots, not simply recolored after the fact.
