# Roman Winning Paylines

Roman Reels needs winning paylines that feel like a real illuminated slot cabinet response, not Violet Fortune overlays reused under a different frame. The line geometry stays identical to the shared ten-payline system so payouts remain clear, but the material language changes to Roman bronze, muted gold, and bright teal glass.

The overlay should be instantly readable on top of symbols without drowning the reel chamber. Number badges sit at the line ends, small center nodes confirm each reel position, and the line glow is strong enough for a win state while still transparent enough for the symbols beneath to remain visible.

This layer is image-only. No runtime text labels, cash language, prize language, or real-money implication is introduced. Accessibility continues through the existing dynamic content description on the winning payline ImageView.
