# Paytable Odds Header Visual Philosophy

## Odds Board

The paytable header should feel like a compact casino machine odds board: structured, luminous, and deliberately engineered. It must visually organize the title, bet sequence, and 3x/4x/5x multiplier headers without adding any text or competing with the bitmap copy already in the interface.

The composition should use soft violet glass, cyan rule lights, and restrained gold column anchors. The center remains calm and readable while the edges and column divisions carry the sense of machinery. The asset must look meticulously crafted, with every rail and glow placed to support comprehension rather than decoration for its own sake.

This is a social-casino reference layer, not a real-money promise. It should avoid cashout cues, prize language, currency marks, or anything that reads like external gambling. The visual information is purely about virtual coin payouts and table structure.

The final image should be transparent, reusable inside the existing modal, accessibility-neutral, and resilient under Android scaling. It should look like master-level interface art: crisp enough for store screenshots, calm enough for Russian image labels, and polished enough to make the paytable feel like part of a real slot cabinet.
