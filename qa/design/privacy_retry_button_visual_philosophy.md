# Privacy Retry Button Visual Philosophy

## Secure Retry

The privacy retry action should feel like a document-console control, not a play button. It uses dark glass, cyan verification rails, restrained gold trim, and a quiet central bay for the existing bitmap retry label.

The button remains textless and image-only. Russian copy stays in `label_retry`, while the button itself communicates a safe reload action through secure-document material rather than game-start energy.

The pressed state should feel physically depressed, with the glow settling inward instead of flashing like a reward. This keeps the privacy error state calm, compliant, and trustworthy.

The final asset is tuned for the existing 180dp by 52dp frame, so it improves polish without shifting layout, changing accessibility, or introducing any external gambling cue.
