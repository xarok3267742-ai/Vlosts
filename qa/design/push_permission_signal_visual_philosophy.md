# Push Permission Signal Visual Philosophy

## Quiet Signal

The push permission pre-prompt should feel like a polite in-game signal, not a system interruption. The visual layer must be image-only: soft notification waves, cyan-violet light, tiny gold status points, and a calm center behind the bell badge. It should look meticulously crafted and restrained, supporting trust instead of shouting for attention.

The composition lives behind the existing Russian image labels. The strongest energy belongs near the top badge, then fades before the body copy and buttons so legibility remains untouched. This is a master-level UI polish layer: controlled rhythm, clean alpha falloff, no text, no clutter, no promotional feeling.

Color should stay within the V Slot cabinet language: violet glass, cyan signal lines, gold micro-sparks, and a dark base that blends into the modal panel. The final asset should feel like it took careful calibration, with every ring and particle placed to make the prompt more premium while preserving the user's sense of control.
