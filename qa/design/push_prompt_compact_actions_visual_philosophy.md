# Push Prompt Compact Actions Visual Philosophy

## Signal Controls

The push pre-permission actions should feel like paired cabinet controls, not squeezed global buttons. Each button is a textless glass instrument with a calm central channel for the existing bitmap label.

The secondary action uses cool steel and cyan rails; the primary action uses magenta energy with gold signal accents. Their shape language is shared so the prompt reads as one designed surface, while the color hierarchy clearly separates defer and allow.

The artwork must stay compliant and specific to notifications only: daily bonus reminders and game updates, with no casino-link, prize, purchase, or real-money implication. Text remains in Russian image labels and accessibility strings.

The final assets are tuned for the two-column prompt row at both normal and 360dp widths. They should look meticulously crafted, downscale cleanly, and avoid layout shift or stretched-looking edges.
