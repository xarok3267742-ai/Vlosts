# Marquee Glass

The slot cabinet should feel like a sealed arcade object, not a stack of flat panels. The visual language is polished glass over machined violet metal: long cyan rails, restrained gold nodes, and a dark translucent crown that sits above the reel window. Every line is placed with painstaking attention so it supports the symbols without stealing attention from them.

Light behaves like engineered hardware. Highlights travel along bevels, LEDs sit in measured intervals, and soft reflections imply depth behind the screen. The craft must look meticulously built, as if the overlay were calibrated against the cabinet for hours.

The composition avoids explanatory text. Information comes from structure: a top marquee bridge, side retainers, faint screw caps, and lens reflections. The result should read as a premium social-casino machine while staying clearly entertainment-only and entirely image-based.

The layer must be decorative and safe over many screen sizes: transparent center, dense edges, clean contrast, no clutter over reels. Master-level execution means every glow is purposeful and every alpha value keeps the UI readable.
