# Slot Paytable Dock Visual Philosophy

## Utility Glow

The paytable button should feel like a real cabinet utility control, not a loose icon. Its support graphic is a compact illuminated dock: cyan edge light, violet glass, and small gold calibration pips that make the lower action row feel engineered.

The layer must be meticulously crafted around the existing 64dp tap target. It should improve discoverability without changing layout, without competing with the spin button, and without introducing text. The center remains calm enough for the button icon to stay sharp.

This is functional slot-machine ambience for a social-casino product using virtual coins only. It should avoid prize, cashout, or real-money cues and communicate only that the paytable is an available information control.

The final image should be transparent, accessibility-neutral, crisp under Android downscaling, and visually consistent with the slot control meter and spin glow assets.
