# Spin Deck

The lower control zone should feel like the physical shelf of a premium slot cabinet: dark polished glass, inset metal, controlled edge light, and a single visual axis that pulls the eye toward the spin button. It must be meticulously crafted but quiet enough to support the existing button art instead of competing with it.

The composition uses a wide transparent chassis with a central cradle and a smaller left dock, connecting the paytable control and spin action into one machine surface. Light is concentrated at the perimeter and under the controls so the interface reads as hardware, not decoration.

Color stays disciplined: violet and cyan define the energized casino electronics, while thin gold accents imply coins, rails, and payout theater. The layer must remain image-only and mostly nonverbal; information is communicated through material, depth, and rhythm.

The finished asset should look painstakingly tuned for a real game screen. It should make the control layout clearer, increase perceived production quality, and preserve accessibility by staying purely decorative beneath existing interactive image buttons.

The paytable dock now carries a compact bitmap label inside the clickable image dock. This is intentionally still image-only: the Russian copy is a rendered WebP layer that makes the left control read as an actionable payout table instead of a decorative grid badge.
