# Social Rules Modal Panel

The social rules dialog uses a dedicated seam-free panel image instead of the shared modal panel. The shared panel has a horizontal divider baked into the bitmap, which reads as an accidental black line below the title when the legal body is centered lower in the dialog.

The dedicated panel keeps the same 900x420 source geometry and the same backplate layering, but removes that divider so the compliance copy sits on clean glass. This preserves the image-only UI rule while making the legal flow look intentional and store-ready.
